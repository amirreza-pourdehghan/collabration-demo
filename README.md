# Collaboration Demo Project

A simple project designed to practice Git and GitHub collaboration workflows.

## Project Overview

This project demonstrates how developers can collaborate using Git and GitHub.

It includes a basic Task Management feature description.

## Features

- Create new tasks
- View existing tasks
- Mark tasks as completed

## How to Contribute

1. Open an issue describing your proposed change.
2. Create a new branch.
3. Make your changes.
4. Commit your changes with a descriptive message.
5. Push your branch to GitHub.
6. Open a Pull Request.
7. Wait for code review and feedback.

## CI/CD

This project uses GitHub Actions to run a simple CI workflow on every push and pull request.

## Running CI Workflow

The CI workflow runs automatically when:
- Code is pushed to the repository.
- A pull request is opened or updated.

You can check the workflow results in the GitHub Actions tab.
